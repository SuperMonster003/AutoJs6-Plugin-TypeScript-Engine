# R7 - Ace, APK Builder, 加密与后台任务

状态: 未开始.

目标: 统一编辑器与运行时语义, 并让开发运行, 后台执行和 APK 发布使用同一
编译规范.

## Ace Language Service

- [ ] Ace 升级并精确锁定 TypeScript 6.0.3.
- [ ] Ace 与 compiler 校验相同 distribution/declarations/profile fingerprint.
- [ ] 共享 URI, diagnostics serialization 和 options normalization 规范.
- [ ] 抽取可复用 `autojs6_ts_host_core.js`.
- [ ] Ace 继续拥有独立 Language Service 生命周期.
- [ ] 不共享 WebView, session, AST 或活体 compiler object.
- [ ] 将 Ace 从单文件模型升级为 project VFS 和 TypeScript module resolution.
- [ ] AutoJs6 host 向 Ace 插件传 versioned snapshot/delta, 不暴露任意路径读取.
- [ ] snapshot 携带 tsconfig, package metadata, declarations 和全部 fingerprint.
- [ ] 支持多个未保存 overlay, revision ID, cancellation 和 stale result 丢弃.
- [ ] project mode 启用后停止屏蔽 TS2307/TS2792/TS7016.
- [ ] project mode 完成前, "一致性"只验收编辑器和 compiler 共同支持的诊断.
- [ ] project mode 完成后, 同 snapshot/options 的完整 diagnostics golden tests 一致.
- [ ] golden comparison 覆盖 code, category, URI, UTF-16 start/length 和 message chain.
- [ ] Ace Language Service 自行计算交互诊断; "运行前检查"仍由 compiler 插件负责.
- [ ] 编辑器关闭或 renderer 崩溃不影响后台编译.
- [ ] open editor overlay 通过 host snapshot 输入 compiler.

## APK Builder

- [ ] 打包前执行 clean project type-check 和 emit.
- [ ] 默认 APK 只包含 JS, map 和 compilation manifest.
- [ ] 普通 Rhino APK 不包含 compiler 或 Node Runtime.
- [ ] 本地和远程 builder 校验 compiler/distribution/declarations/profile fingerprint.
- [ ] 构建可复现, 相同输入得到相同 JS/map/manifest.
- [ ] 加密构建保护 JS, map 和 URI manifest.
- [ ] release map 默认不携带 `sourcesContent`.
- [ ] 加密 TS 在 builder snapshot 阶段解密到内存/加密 staging, 编译后立即清理.
- [ ] 首个 GA 的发布 APK 不支持运行中编译 late external TS.

`bundled compiler` 不属于首个 GA. 若 Post-GA 要支持动态外部 TS, 必须另立
路线并冻结 APK 内 compiler host, WebView/worker 沙箱, distribution 更新,
内存/进程生命周期, 输入权限, 包体门槛, Source Map 隐私和离线验收; 不得仅通过
打包 `typescript.js` 开启.

## 后台场景

- [ ] 定时任务在编辑器未打开时编译和执行.
- [ ] Tasker/外部 URI 启动路径通过.
- [ ] loop 和长运行脚本的 compiler 生命周期正确.
- [ ] 插件升级期间已有执行使用 execution-scoped artifact.
- [ ] 插件被禁用/卸载时给出明确错误, 不回退到正则 stripping.
- [ ] 低内存回收后可重建 compiler service.
