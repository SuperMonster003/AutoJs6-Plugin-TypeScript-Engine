# R4 - Rhino 执行适配

状态: 未开始.

目标: 让 Rhino 消费完整 TypeScript 编译产物, 并将诊断和运行栈映射回
原始 TypeScript.

## 模块执行

- [ ] 实机验证并冻结 Rhino compiler profile revision/target 兼容矩阵.
- [ ] Rhino profile 输出 CommonJS.
- [ ] module loader 从 `CompilationBundle` 读取 JS, 不读取原 TS.
- [ ] 支持入口, 普通依赖, 循环依赖和 JSON 依赖.
- [ ] 验证 TypeScript downlevel helpers.
- [ ] 首版优先 inline helpers, 避免不受控 `tslib`.
- [ ] 明确 Promise, Symbol, iterator 和 async runtime polyfill 边界.
- [ ] 混合 TS/JS AutoJs6 项目通过.

## Source Map

- [ ] 内部坐标统一为 0-based line + UTF-16 code-unit column; UI/字符串栈转 1-based.
- [ ] `RhinoJavaScriptEngine` 使用 `ScriptCompileSpec`.
- [ ] `SourceMapV3.parse` 解析 compiler map.
- [ ] 编译阶段通过 `sourceMapper` 注入映射.
- [ ] generated/source URI 使用受控 `autojs://` 形式.
- [ ] compiler map 与 CommonJS wrapper map 组合.
- [ ] 语法错误回到 TS 文件, 行和列.
- [ ] 首个 GA 的 Rhino 运行栈契约冻结为原 TS 文件和行.
- [ ] UI/API 不展示或虚构 Rhino 运行栈列号.
- [ ] Rhino runtime `MappedStackFrame.column=null`, 不能用 0 表示 unknown.
- [ ] Rhino fork `ScriptStackElement` 列号扩展作为 Post-GA 改进单独评估.

## 退出条件

- [ ] enum, namespace, class fields, optional chaining 和 async fixture 通过.
- [ ] throw, timer, Promise rejection 和 async/await 栈通过.
- [ ] 用户读取 `Error.stack` 时也可映射.
- [ ] 中文路径, 空格路径, CRLF, BOM 和 Unicode 通过.
- [ ] malformed map 安全失败且不崩溃宿主.
- [ ] golden tests 只按首个 GA 契约验收: diagnostics 到列, runtime stack 到行.
