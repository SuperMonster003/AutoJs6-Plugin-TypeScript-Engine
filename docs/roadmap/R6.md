# R6 - Source Map, 缓存, 安全与性能

状态: 未开始.

目标: 把编译从可用能力提升为可长期运行, 可缓存, 可诊断且安全的生产能力.

## Source Map 和异常

- [ ] 建立 execution-scoped `SourceMapRegistry`.
- [ ] 引入结构化 `ScriptCompilationException`.
- [ ] 引入结构化 `MappedStackFrame`.
- [ ] original/generated URI/line/column 与 mapping status 均显式可空/可区分.
- [ ] 内部坐标使用 0-based line 和 UTF-16 code-unit column, UI 统一转 1-based.
- [ ] unmapped/generated-only frame 保留生成坐标, 不伪造 original 坐标.
- [ ] `StackFrameTargetResolver` 按 URI/map base/project root 定位.
- [ ] compiler map, wrapper map 和 bootstrap map 可组合.
- [ ] stack formatter, 用户读取 `Error.stack` 和 UI 跳转复用同一 mapper.
- [ ] map 注册在执行结束后及时释放.
- [ ] map 路径不能逃逸项目作用域.
- [ ] map 大小和 segment 数量有上限.

## 缓存

- [ ] cache key 包含源码图 hash.
- [ ] cache key 包含 compiler version 和 distribution fingerprint.
- [ ] cache key 包含 normalized compiler options.
- [ ] cache key 包含 target profile revision 和 runtime capabilities fingerprint.
- [ ] cache key 包含 AutoJs6 declarations version/hash.
- [ ] cache 写入应用内部目录, 不污染用户项目.
- [ ] 支持增量 build info, 但发布构建执行 clean check.
- [ ] 依赖, tsconfig, compiler 或 declarations 变化必定失效.
- [ ] 缓存损坏时安全丢弃并重编译.

## 安全和隐私

- [ ] archive bomb, zip slip, path collision 和超限输入测试.
- [ ] diagnostics 数量和单消息长度有界.
- [ ] worker 不访问网络和宿主任意路径.
- [ ] 加密源码只保留在内存或加密临时区.
- [ ] renderer/process death 后清理明文和 FD.
- [ ] late external TS 不触发网络, 宿主回读或隐式 compiler 生命周期.
- [ ] release map 默认 `sourcesContent=false`.
- [ ] 日志不输出源码正文, 密钥或绝对私有路径.

## 性能门槛

- [ ] 10 文件/200 KiB 冷启动+编译 p95 <= 3 s.
- [ ] 同项目单文件增量 p95 <= 750 ms.
- [ ] compiler service + renderer 峰值 PSS 目标 <= 150 MiB.
- [ ] cancel 后 1 s 内停止或终止 worker.
- [ ] renderer death 最多重试一次.
- [ ] 并发 admission 和背压行为有压力测试.
- [ ] QV770340J7 保存基线报告, 不占用 QV710AF65F soak 设备.
