# R0 - 插件基线与协议

状态: 已完成.

目标: 建立不会误依赖 Node Runtime 的独立 Android 插件, 锁定编译器版本并建立
可演进的 Binder envelope 基线, 让后续真实编译宿主可以在稳定边界内落地.

## 工程与版本

- [x] 创建 `AutoJs6-Plugin-TypeScript-Engine` 独立 Gradle 工程.
- [x] 对齐 AutoJs6 `6.8.0 Alpha7`, build `5253`.
- [x] 对齐 min SDK 24, compile/target SDK 36.
- [x] 插件版本初始化为 `0.1.0`, version code `1`.
- [x] 精确锁定 `TYPESCRIPT_VERSION=6.0.3`.
- [x] 记录 npm tarball, SHA-1 和 SRI SHA-512.
- [x] 使用 `:app + :plugin-api:common-plugin-api + :plugin-api:typescript-api`.
- [x] 只生成 universal APK, 不声明无意义的 native ABI splits.

## 插件发现与进程

- [x] 实现 `TypeScriptPluginInfoService`.
- [x] 实现 `TypeScriptCompilerPluginService`.

- [x] compiler service 运行于 `:typescript_compiler` 私有进程.
- [x] 所有 exported service 使用 `org.autojs.permission.PLUGIN`.
- [x] Manifest 不申请 `INTERNET` 权限.

- [x] plugin variant 从单一 `TYPESCRIPT_VERSION` 派生, 不维护第二份版本常量.

## IPC 和诚实能力协商

- [x] 建立 provisional compiler contract v1.
- [x] 使用 append-only AIDL + primitive-only Bundle envelope.
- [x] 定义 request, ticket, progress, result 和 compiler info 的稳定 key 命名空间.
- [x] 使用 `ParcelFileDescriptor` input/output archive, 避免 Binder 1 MiB 限制.
- [x] 定义 Rhino 和 Node target profile, 但不让 compiler 依赖 Node.
- [x] 定义 contract version, request ID, mode, transport version, timeout 和取消入口.
- [x] 定义有限输入预算和稳定错误码.
- [x] R0 metadata 明确返回 `compilerAvailable=false`.
- [x] prewarm 校验 contract/type/size/timeout, 并明确返回 R0 unavailable.
- [x] 合法 compile 请求明确返回 `ERR_AUTOJS6_TYPESCRIPT_R0_NOT_AVAILABLE`.
- [x] 被拒绝请求关闭传入 FD, 不泄漏 descriptor.
- [x] R0 不接受 job, 不虚构 job token/cancel 成功或发送 callback.
- [x] 记录 R1 只冻结 Binder envelope/FD 状态机, R2 再冻结 archive schema.
