# R3 - AutoJs6 脚本准备管线与路由

状态: 未开始.

目标: 在 AutoJs6 创建任何执行引擎之前加入统一 TypeScript preparation,
并解除 `.ts = Node` 的现有耦合.

## 宿主 API

- [ ] 将 `typescript-api` 同步到 AutoJs6 主仓库.
- [ ] 主 APK 加入 compiler service package visibility query.
- [ ] 基于通用 `AidlPluginHost` 实现薄 compiler client.
- [ ] 校验插件启用, 信任, action, permission, host version 和 contract.
- [ ] 使用 dedicated binding lease 覆盖整个编译生命周期.
- [ ] 构造并验证 input/output archive.
- [ ] 插件缺失时返回稳定, 可本地化的 compiler unavailable 错误.

## ScriptPreparationPipeline

- [ ] 在 `RunnableScriptExecution` 创建引擎前准备 TypeScript.
- [ ] 准备结果成为 execution-scoped prepared source.
- [ ] loop 执行复用 prepared bundle, 不逐轮重编译.
- [ ] 独立 `.ts` 被视为虚拟单文件项目.
- [ ] 项目执行解析 `project.json + tsconfig.json`.
- [ ] host 按受控 inventory 规则传项目文件和显式允许的依赖根, 不解析 TS 模块图.
- [ ] snapshot 包含 tsconfig, package metadata, sources, declarations 和 overlay.
- [ ] compiler plugin 在 VFS 内完成语义 module resolution.
- [ ] 编辑器运行合并未保存 overlay.
- [ ] 清单内的加密源码在执行前按需解密, 且只进入内存/加密 staging snapshot.
- [ ] snapshot 在启动编译前封闭; 运行中不得回读宿主任意项目路径.
- [ ] runtime resolver 仅可命中 output manifest 中已生成的模块.
- [ ] `.ts/.mts/.cts` dynamic specifier 到生成扩展名的映射明确且可测试.
- [ ] 未命中, 歧义或越界 dynamic specifier 使用稳定错误码.
- [ ] 首个 GA 对 late external TypeScript 返回稳定 unsupported 错误.
- [ ] 编译失败时不创建 Rhino/Node 引擎.
- [ ] Activity 启动路径不在主线程同步等待编译.

## 路由

- [ ] `.ts` 从 Node 文件判断中移除, 改为 TypeScript source kind.
- [ ] `.d.ts/.d.mts/.d.cts` 永远不可执行.
- [ ] `.tsx` 在未支持前给出明确错误.
- [ ] 路由优先级为 directive > project type > TS default > Rhino.
- [ ] 默认独立 `.ts` 选择 Rhino.
- [ ] UI 和文档固定首版矩阵: Rhino `.ts`; Node `.ts/.mts/.cts`.
- [ ] Node 可用性检查只留在最终 Node adapter.

## 退出条件

- [ ] Node Runtime 未安装时 Rhino `.ts` 成功.
- [ ] Node Runtime 禁用时 Rhino `.ts` 成功.
- [ ] Ace 未安装或 LSP 关闭时后台 `.ts` 成功.
- [ ] 编译失败无引擎泄漏, 无半成品输出.
- [ ] 现有 JavaScript/Rhino/Node 路由回归测试全部通过.
