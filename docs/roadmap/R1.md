# R1 - 官方编译器发行包与真实宿主探针

状态: 已完成.

目标: 将 R0 的协议基线推进为可重复构建的官方 TypeScript 6.0.3 发行包和
受限 compiler host. R1 仍不接入 AutoJs6 正式执行链.

发行目录 schema 与 fingerprint 算法见
[Compiler Distribution v1](../architecture/COMPILER_DISTRIBUTION_V1.md).
R1 冻结的 raw ZIP 结构、canonical path 和基础配额见
[ZIP Archive Container v1](../architecture/ARCHIVE_CONTAINER_V1.md).
受限宿主, prewarm 语义, runtime golden 和当前证据见
[Restricted Compiler Host R1](../architecture/COMPILER_HOST_R1.md).

当前证据覆盖 Android 12/API 31 与 Android 13/API 33 上的 debug 远程 Binder
prewarm, 每台设备 100 次热探针, timeout 后的 Worker 重建恢复, 真实 renderer
退出门禁, 连续 timeout 的 epoch recovery 合并及 10 轮 compiler process
restart. service destruction teardown/rebind, compiler process FD 边界和 API 33
WebView 109 下的 Node/Ace 四种安装态也已通过. minified release 已在 Android 13
真机通过. API 31/33 的 service + renderer PSS、distinct-request correlation、
双冷 Rhino unsupported/watchdog/rebind、debug-only
accepted/cancel/timeout/death lifecycle，以及冻结 AAR 双向兼容门禁均已在两台
真机通过. ZIP literal corpus 另在 API 24/25/31/33 各通过 1/1.

官方 Play Store x86 镜像的 stock API 24/Chrome `51.0.2704.90` 与 API 25/Chrome
`55.0.2883.91` 只通过 remote Binder transport；两者在
`compiler-host.js:73` 报 `Unexpected token )` 后由有界 timeout 收口. 同一
AVD 更新并明确选中同签名 Chrome `119.0.6045.194` 后，API 24/25 均通过真实
TypeScript 6.0.3 Worker golden、完整 5 项 Binder/FD、连续 timeout recovery、
service destruction/rebind 和 10 轮冷 compiler process restart. Chrome 119
可能在 warm baseline 后保留 compiler process 自身的 `statm`/`status` 两个只读
procfs telemetry FD；门禁只接受这个完整二元组，其他增长或 staging archive
残留仍失败. 该 modern-provider matrix 关闭了最后一项 R1 退出证据，因此 R1
已完成；R1 仍不接入正式执行链，`compilerAvailable=false` 继续为权威状态.

## 发行包

- [x] 从 lock 指定的 npm tarball 获取发行物.
- [x] 下载前后验证 SRI SHA-512, tarball SHA-1 和最终 SHA-256.
- [x] 只提取 `lib/typescript.js`, `lib/typescript.d.ts`, `lib/lib*.d.ts`,
  `LICENSE.txt` 和 `ThirdPartyNoticeText.txt`.
- [x] 拒绝 tar path traversal, symlink, hardlink, duplicate path 和超限文件.
- [x] 生成 `distribution.json` 和逐文件 SHA-256.
- [x] 构建时在受限宿主内校验 `ts.version` 与 lock 一致.
- [x] 禁止 Gradle 自动跟随 `latest`, `^` 或 `~`.
- [x] APK 中只存在一份 compiler JS.
- [x] 建立可供 Ace 后续复用的 distribution schema.
- [x] 分别记录 compiler, standard libs 和 generator fingerprint.

## WebView/Worker 宿主

- [x] compiler WebView 不复用 Ace activity 或 editor WebView.
- [x] 使用私有 HTTPS asset origin.
- [x] 只允许显式 asset allowlist.
- [x] 禁用 file/content access, network, storage 和 window opening.
- [x] compiler API 只暴露 request ID 和内存 VFS 消息.
- [x] TypeScript 在 Web Worker 中加载.
- [x] Kotlin 主线程只负责 WebView 生命周期, 不执行类型检查.
- [x] compiler worker 超时可 terminate 并重建.
- [x] renderer death 最多自动重试一次.
- [x] service 销毁时释放 WebView, worker 和 pending callback.
- [x] 用同一 TS 6.0.3 发行包实现 debug-only 专用 Rhino compiler context
  可行性探针, 锁定 artifact digest、Rhino source commit 与 AutoJs6 consumer
  commit.
- [x] 在真实设备保存 WebView prewarm golden 与至少两个冷 Rhino 进程的输出,
  PSS、首个语法失败邻域、取消 watchdog 延迟和 rebind 恢复证据.
- [x] 只有 TS 6.0.3 golden tests 全部一致时才可能重新评审 Rhino fallback;
  当前 unsupported 结果永远不能启用 fallback.
- [x] Rhino probe 不通过时固定记录 `supported=false`、
  `fallbackEligible=false`, 不降低到 TS 4.2.4 或任何旧 TypeScript.

## Binder/FD 冻结门禁

- [x] 使用真实 `:typescript_compiler` 进程完成 bind, capability 和 R0 reject
  instrumentation test.
- [x] 使用 seekable staging file 覆盖 caller/service 独立 FD ownership 和 close 时序.
- [x] 验证 R0 reject 在有界观察窗内为 0 callback.
- [x] 用仅 debug、same-UID 的内部 lifecycle probe 验证 accepted 且双方存活为
  exactly-one callback；production/external `startCompilation` 仍全部拒绝.
- [x] 验证 cancel/timeout 正常回调；callback death 由 service 清理，
  service death 由代表性 client arbiter 合成本地终态.
- [x] 冻结 append-only AIDL transaction 顺序和 primitive-only Bundle 规则.
- [x] 冻结 ZIP v1 容器/printable-ASCII path/ASCII casefold/压缩方法/基础配额,
  但不冻结项目 manifest 或 Unicode 原名映射.
- [x] 保存 v1 API AAR, Binder transaction 和 Bundle golden fixtures.
- [x] 用旧 client AAR 对新 service, 新 client 对旧 service 做兼容测试.
- [x] `assembleRelease` 的 minified APK 完成安装, discovery 和 bind smoke test.
- [x] R1 明确不冻结 input/output manifest, diagnostics schema 或 engine
  compiler profile.

- [x] `transpileModule` enum emit 产生可执行 JS.
- [x] 语法错误返回 code, message, source URI, line 和 column.
- [x] Source Map `version=3` 且 mappings 非空.
- [x] release probe 禁止生成 inline source content.
- [x] 10 个冷 compiler process 和 100 次热调用保持 golden/fingerprint 稳定,
  compiler service FD 有界且不残留 staging archive.
- [x] 在 API 31/33 真机运行 `R1PssAndCorrelationInstrumentationTest`, 校准
  compiler service + 独立 renderer PSS, 并保存 distinct-request correlation
  门禁证据.
- [x] Node/Ace 的 none, Node-only, Ace-only 和 both 安装态均不影响 remote
  prewarm golden/fingerprint; 显式 opt-in 的 `verifyR1OptionalPluginMatrix`
  可在指定 disposable emulator 上重复该四态门禁并保存证据报告.
- [x] distribution fingerprint 在进程重启后稳定.
- [x] API 24/25 官方 Play Store x86 AVD 在明确选中的 Chrome
  `119.0.6045.194` 下通过真实 Worker、100 次热探针、timeout recovery、
  teardown/rebind 和 10 轮冷进程门禁；stock Chrome 51/55 保留为不兼容负基线.
- [x] 上述 Binder/FD 和真实 compiler 探针通过后，冻结顶层 envelope v1；
