# LOCAL-TS-2026-08-25-01: declaration upgrade coupling

| 字段 | 值 |
|---|---|

| 来源 | S10-3 TypeScript distribution upgrade rehearsal |
| 首次确认 | 2026-08-25 |
| 分类 | maintenance/tooling |
| severity | medium: 阻止安全升级演练, 不影响当前 6.0.3 用户编译 |
| 影响范围 | R2 declaration distribution generator |

## 接收

目标是用官方三摘要锁定的 TypeScript 6.0.2 重放 `6.0.2 -> 6.0.3` 升级。compiler
distribution 可以生成, 但 declaration generator 同时把 common version、asset root、
distribution fingerprint、标准库数量和字节数重复冻结为 6.0.3。合法的 6.0.2
declaration lock 因此在读取阶段被拒绝, 无法验证后续 profile identity 与缓存失效。

稳定症状不是 TypeScript diagnostic, 而是 build-time maintenance failure:

```text
R2 common declaration lock is not the frozen TypeScript 6.0.3 component
```

没有 `diagnostics.json`; profile、源码和用户设备均与失败无关。

## 最小复现

1. 保留 production `compiler-distribution.lock.json` / `r2-declarations.lock.json` 不变。
2. 新建官方三摘要锁定的 6.0.2 rehearsal compiler lock。
3. 从经过验证的 6.0.2 compiler manifest 写 common declaration identity。
4. 让 `GenerateR2DeclarationDistribution` 消费该 lock 与 6.0.2 distribution。
5. 修复前在 lock reader 阶段稳定得到上述拒绝, 尚未进入 declaration byte 生成。

修复后的永久回归命令:

```powershell
.\gradlew.bat :app:verifyTypeScriptUpgradeRehearsal `
  --offline --rerun-tasks --console=plain
```

## 根因

供应链 authority 本来已经由 declaration lock 与独立验证的 compiler
`distribution.json` 双向核对, 但生成器又保存了一份 production 6.0.3 常量集合。
这些重复常量没有增加安全性, 却把“只接受受验证的稳定 6.x”错误收紧成“只接受一次
具体发行”。asset root 也由常量生成, 使合法 baseline 会指向错误版本目录。

## 修复

- production generator 只接受 package `typescript` 与稳定 `6.x.y`, 7.x 继续 fail
  closed;
- common version、distribution fingerprint、standard-library fingerprint/count/bytes
  从 canonical declaration lock 读取, 再与实际验证过的 compiler manifest exact
  cross-check;
- `typescript/<version>` asset root、binding 与 source descriptor 从 lock version
  动态推导;
- 6.0.3/6.0.2 指纹只留在测试 fixture 和结构化演练证据, production generator 不再
  硬编码当前发行身份;
- 新增 6.0.2 positive 与 7.0.2 rejection 单测。

安全边界没有放宽: tarball exact URL、SHA-1/SHA-256/SRI、archive allowlist、canonical
lock、stable 6.x、manifest cross-binding 和 profile 内容指纹规则全部保留。

## Changelog 与关闭

changelog 决策: `none-maintenance-only`。

理由: production TypeScript 仍为 6.0.3, production lock、compiler/declaration bytes、
签名 APK 大小和 SHA-256 均未变化; 本次修复只移除未来升级演练的重复耦合。Roadmap、
升级手册、v0.6.0 本地发布说明和本记录已说明维护变化, 不向十语言用户 changelog
伪造新功能或 bug 修复。

关闭条件均满足: 最小复现转为自动测试、稳定 6.x positive/7.x negative、有缓存和
Worker/release smoke 证据、无用户数据、无远端副作用。
