Instala el APK firmado de la versión oficial junto a AutoJs6 compatible. Activa TypeScript Engine en el centro de complementos y ejecuta un proyecto .ts o .tsx. Rhino no necesita Node.js Runtime; los proyectos Node.js sí.

APK: `arm64-v8a` / `armeabi-v7a` / `x86_64` / `x86` / `universal`

```typescript
const message: string = 'Hello, TypeScript';
console.log(message);
```

Requiere Android 7 (API 24) y Chrome/WebView 119 o posteriores. Incluye TypeScript 6.0.3. No admite addons nativos npm, scripts de instalación ni emitDecoratorMetadata. La distribución pública sigue a la del host compatible; las pruebas históricas no certifican cada APK posterior.
