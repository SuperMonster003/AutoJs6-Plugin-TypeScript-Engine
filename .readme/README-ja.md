互換性のある AutoJs6 と公式リリースの署名済み APK をインストールします. プラグインセンターで TypeScript Engine を有効化し, .ts または .tsx プロジェクトを実行します. Rhino に Node.js Runtime は不要ですが, Node.js プロジェクトには必要です.

APK: `arm64-v8a` / `armeabi-v7a` / `x86_64` / `x86` / `universal`

```typescript
const message: string = 'Hello, TypeScript';
console.log(message);
```

Android 7 (API 24) 以降および Chrome/WebView 119 以降が必要です. TypeScript 6.0.3 を同梱しています. native npm addon, パッケージインストールスクリプト, emitDecoratorMetadata は非対応です. 公開配布は対応ホストのリリースに合わせます. 過去の検証は後続 APK の合格を意味しません.
