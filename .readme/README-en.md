Install the signed APK from the official release alongside a compatible AutoJs6 host. Enable or activate TypeScript Engine in the plugin center, then run a .ts or .tsx project. Rhino works without Node.js Runtime; Node.js projects require that runtime plugin.

APK: `arm64-v8a` / `armeabi-v7a` / `x86_64` / `x86` / `universal`

```typescript
const message: string = 'Hello, TypeScript';
console.log(message);
```

Requires Android 7 (API 24) or newer and Chrome/WebView 119 or newer. The included compiler is TypeScript 6.0.3. Native npm addons, package install lifecycle scripts and emitDecoratorMetadata are unsupported. Public distribution follows the compatible host release; the historical acceptance records do not certify every later APK.
